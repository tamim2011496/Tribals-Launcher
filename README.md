# Tribals Launcher v1.0.0

The first public release of the **Tribals Launcher**, a standalone desktop app for playing [tribals.io](https://tribals.io).

<img width="522" height="361" alt="Tribals Launcher" src="https://github.com/user-attachments/assets/152ebf87-9631-48de-96b4-d521c24caf34" />

## Features
- Opens the official tribals.io website in its own dedicated fullscreen window
- No browser tabs or address bar, just the game
- Simple Windows installer with a built-in uninstaller

## Download
Download **TribalsSetup.exe** from the assets below.

## Install
1. Run `TribalsSetup.exe` (administrator permission is required).
2. Choose an install folder, or keep the default: `C:\Program Files\Tribals`.
3. Launch **Tribals** from the Start Menu.

## Uninstall
Go to **Settings → Apps → Tribals → Uninstall**.

## Requirements
- Windows 10 or later (64-bit)
- An internet connection

## Notes
- The installer is not code-signed yet, so Windows SmartScreen may show a warning. Click **More info → Run anyway** to continue.
- The launcher only loads the official tribals.io website.
